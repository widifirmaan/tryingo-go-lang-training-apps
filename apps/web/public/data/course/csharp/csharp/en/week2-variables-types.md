## Program: Data Types

```csharp
int number = 42;
string name = "Budi";
double price = 99.99;
bool isActive = true;

var message = "Hello";
var count = 10;

Console.WriteLine($"Number: {number}");
Console.WriteLine($"Name: {name}");
Console.WriteLine($"Price: {price:C}");
```
