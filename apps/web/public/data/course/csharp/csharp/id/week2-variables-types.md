# Variables & Data Types

> C# | Modul 2

## Tujuan Pembelajaran

- Mendeklarasikan variabel dengan tipe data
- Memahami tipe value dan reference
- Menggunakan var dan explicit typing
- Mengkonversi tipe data (casting)

---

## Program: Data Types

```csharp
int number = 42;
string name = "Budi";
double price = 99.99;
bool isActive = true;

var message = "Hello";
var count = 10;

Console.WriteLine($"Number: {number}");
Console.WriteLine($"Name: {name}");
Console.WriteLine($"Price: {price:C}");
```
