# Positioning — Tempel Warung

> **Kategori:** CSS3 | **Level:** CSS3 Lengkap | **Minggu 6:** Positioning

## Tujuan Pembelajaran

- `position: relative/absolute/fixed/sticky`, `z-index` tumpuk, `top/left`

---

## Program

```html
<div style="position: relative; border: 1px solid #ddd; padding: 16px;">
  Produk
  <span style="position: absolute; top: 8px; right: 8px; background: red; color: white; padding: 2px 6px; border-radius: 8px;">Promo</span>
</div>
<div style="position: fixed; bottom: 16px; right: 16px; background: #2E5B44; color: white; padding: 12px; border-radius: 50%;">WA</div>
```

`relative` induk, `absolute` anak di pojok, `fixed` nempel layar, `sticky` nempel saat scroll.

---

## Ringkasan

Minggu 6: **Tempel** — `relative`/`absolute`/`fixed`.
