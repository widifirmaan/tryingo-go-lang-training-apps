# Layout Flexbox — Rak Geser

> **Kategori:** CSS3 | **Level:** CSS3 Lengkap | **Minggu 4:** Layout Flexbox

## Tujuan Pembelajaran

- `display: flex`, `justify-content`, `align-items`, `gap`, `flex-wrap` — susun kardus sejajar

---

## Program

```html
<div style="display: flex; gap: 12px; flex-wrap: wrap; justify-content: center;">
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px; width: 180px;">Beras<br>Rp 62.000</div>
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px; width: 180px;">Bayam<br>Rp 5.000</div>
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px; width: 180px;">Telur<br>Rp 28.000</div>
</div>
```

**Tanpa flex:** kardus turun ke bawah. Dengan `flex` sejajar, `gap` jarak, `wrap` pindah baris jika sempit.
