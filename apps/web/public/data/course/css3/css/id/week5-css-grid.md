# CSS Grid — Rak Kotak-Kotak

> **Kategori:** CSS3 | **Level:** CSS3 Lengkap | **Minggu 5:** CSS Grid

## Tujuan Pembelajaran

- `display: grid`, `grid-template-columns: repeat(3, 1fr)`, `gap`, `grid-column` — rak kotak rapi

---

## Program

```html
<div style="display: grid; grid-template-columns: repeat(auto-fill, minmax(180px, 1fr)); gap: 12px;">
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px;">Beras<br>Rp 62.000</div>
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px;">Bayam<br>Rp 5.000</div>
  <div style="border: 1px solid #ddd; padding: 16px; border-radius: 12px;">Telur<br>Rp 28.000</div>
</div>
```

`auto-fill minmax(180px,1fr)` = HP 1 kolom, laptop 3 kolom otomatis.
