---

## Explanation

Here is a detailed explanation of the material:

### Headings
`<h1>` to `<h6>` — heading hierarchy. Use one `<h1>` per page for SEO. Do not skip heading levels.

### Text Formatting
`<strong>` — important (bold). `<em>` — emphasis (italic). `<mark>` — marked text. `<small>` — small text. `<del>` — deleted text. `<ins>` — inserted text.

### Quotes & Code
`<blockquote>` — long quotation. `<cite>` — quote source. `<pre>` — preformatted text. `<code>` — inline program code.

### Entities
`&amp;` for `&`. `&lt;` for `<`. `&gt;` for `>`. `&copy;` for ©. `&mdash;` for —.
